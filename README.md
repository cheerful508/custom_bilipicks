# BiliPicks 乐学版

基于开源项目 [limin112/bilipicks](https://github.com/limin112/bilipicks)（MIT）改造，给两个孩子（9 岁、11 岁）各一个档案，内容可以自己改，学完有星星和庆祝，还有「乐探究」。纯静态网站，无需构建、无需服务器。

## 文件
| 文件 | 作用 |
|---|---|
| `index.html` | 孩子用的学习站（首页、路线、播放、乐探究、我的成长） |
| `editor.html` | 可视化编辑器（改档案、路线、视频、探究题、奖励；备份） |
| `tv.html` | 大屏版：望远鲸、电视、投影仪、大屏平板（触屏 + 遥控器/键盘都能操作；遥控器 ◀ ▶ 默认快退/快进，返回键回首页） |
| `device-check.html` | 设备自检页：看这台设备的浏览器、触屏、B 站播放器是否正常 |
| `大屏验证指南.md` | 一步步在望远鲸上验证的操作说明 |
| `core.js` | 共用内核：档案、星星/等级/徽章、庆祝特效、乐探究模板与弹窗 |
| `kids.js` / `kids.css` | 首页成长看板、档案切换、「我的成长」「乐探究」页 |
| `data.js` | 公共视频清单（原项目数据，所有孩子共用） |
| `update.py` | 原项目维护脚本（检查失效视频、给公共清单加视频） |

## 使用
1. 双击 `index.html` 就能用；要长期用，传到 GitHub Pages / Cloudflare Pages / Netlify，根目录就是网站。
2. 第一次打开选「我是谁」（默认「哥哥」「弟弟」）。右上角头像可随时换人。
3. 编辑器：`editor.html`（路线页和播放页也有「✏️」入口）。改动自动保存，点「用 TA 的身份预览」看效果。
4. 家长口令（编辑器 → 档案）可选：进入编辑器、确认「已兑现」时需要。只能防随手点开，不是安全措施。

## 每个孩子互相独立的内容
进度、星星、徽章、探究记录、自己的路线、添加/隐藏/改过的视频、自己的探究课题、心愿清单。公共清单 `data.js` 不会被改动。

## 激励与庆祝
- 星星：看完视频 +3，过关 +15，动手任务 +10，乐探究 +6（真动手再 +6，讲给家人 +2），自由课题首次 +10。同一件事只发一次星星，刷不了分。
- 8 级称号、16 个徽章、连续打卡、每日目标、7 日图表。
- 撒花、音效（可关）、升级/徽章弹窗；心愿商店用星星兑换，家长可直接发奖励星星。

## 乐探究
- 看完视频后弹出：想一想 → 动手做（带材料、步骤、安全提示）→ 讲给家人听 → 自评打星。按视频分类自动生成题目，11 岁以上多一道进阶题；编辑器里可改每条视频的探究题。
- 自由课题库：9 个内置（纸飞机、沉浮、纸桥、影子测高、反应速度尺、种子发芽、我来当 AI……），可自己添加。
- 探究本：保存全部记录，可复制文字、打印。

## 数据与备份
全部存在浏览器 localStorage，换设备不同步、清浏览数据会丢。编辑器 →「备份与重置」可导出/导入 JSON，也可把一个孩子的设置复制给另一个。

## 说明
- 去掉了原项目的电视版（`tv.html`、`android/`）；它用旧的进度键，和多档案不兼容。需要的话可以另行适配。
- 孩子自己添加的视频建议家长过目。读取 B 站视频信息依赖 B 站公开接口，失败时手填标题即可。
